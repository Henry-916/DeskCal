# DeskCal

[![CI](https://github.com/kangkangStudent/DeskCal/actions/workflows/ci.yml/badge.svg)](https://github.com/kangkangStudent/DeskCal/actions/workflows/ci.yml)
[![GitHub release](https://img.shields.io/github/v/release/kangkangStudent/DeskCal)](https://github.com/kangkangStudent/DeskCal/releases/latest)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

DeskCal 是一款面向 Windows 10/11 的本地优先桌面日历。它专注于快速记录、可靠提醒、桌面常驻和中国用户熟悉的日历信息，不依赖账号或云端服务。

当前版本：**0.5.0 时间规划版**

## 0.5.0 新增

- 多日历管理：创建、改名、换色、显示/隐藏和安全删除
- 日程可以归属工作、生活、学习等不同日历
- 新建和编辑日程时实时检测时间冲突，允许确认后继续保存
- 冲突日程在月视图、周视图和列表中突出显示
- 周视图支持把日程拖到其他日期，并按落点调整开始时间
- 周视图日程卡底部支持拖动调整持续时间
- 拖拽和快速调整后提供“撤销”
- 单击日程打开快速编辑卡，可延后30分钟、延后1小时、移到明天或标记完成
- 重复日程支持“仅本次”“本次及以后”“整个系列”三种编辑和删除范围

## 0.4.0 功能

- 月视图与周视图一键切换，周视图直接展示每天的日程摘要
- “未来七天”聚合列表，可连续查看即将发生的日程
- 全局搜索，可按标题、地点、备注和分类定位日程
- 中文自然语言快速录入，支持“明天下午3点开会，提前30分钟提醒”等表达
- 支持识别今天、明天、后天、下周、星期、绝对日期、上午/下午、提醒、重复和分类
- 删除日程进入回收站，可恢复或永久删除
- 重复日程支持“仅跳过本次”，不会影响整个系列
- 新增 `Ctrl + K` 快速录入和 `Ctrl + F` 全局搜索

## 中国日历

- 每个日期格显示农历日期，支持闰月
- 春节、元宵、端午、七夕、中秋、重阳等传统节日
- 完整二十四节气
- 2026 年国务院法定放假及调休安排
- “休”“班”角标区分法定假期和周末调休工作日
- 周六、周日列标题、日期文字和背景强化
- 右侧日期详情显示完整农历、干支、生肖、节日和假期进度
- 农历、传统节日、纪念日、节气、休班角标、周末强调均可独立开关
- 中国日历信息离线可用

## 日程与提醒

- 月视图、周视图、日期选择、未来七天和当日日程列表
- 日程新增、编辑、软删除、恢复、永久删除和完成状态
- 全天日程、开始/结束时间、地点、分类、颜色与备注
- 一个日程支持多个提醒
- 每天、工作日、每周、每月、每年重复
- 每隔 N 天/周/月/年重复，可设置截止日期或重复次数
- 重复日程可跳过单次发生
- 重复日程可修改或删除本次、本次及以后、整个系列
- 多日历、时间冲突检测和快速编辑
- Windows 系统通知与休眠唤醒后的遗漏提醒

## 桌面体验与数据

- 系统托盘、隐藏到托盘和开机启动
- 桌面组件、普通窗口、始终置顶三种模式
- 透明度、鼠标穿透、浅色/深色主题
- 多显示器移除后的可见区域恢复

## 快捷操作

- `Ctrl + N`：新建日程
- `Ctrl + K`：打开中文快速录入
- `Ctrl + F`：聚焦全局搜索
- 双击日历日期：在该日期新建日程
- 关闭按钮：隐藏到系统托盘
- 鼠标穿透开启后：从托盘菜单关闭鼠标穿透

## 代码结构

- `src/calendar-core.js`：日期、重复规则和提醒计算
- `src/chinese-calendar.js`：农历、节日、节气和年度法定休班数据
- `src/quick-input.js`：中文自然语言快速录入解析
- `src/planner-core.js`：冲突检测、时间调整和重复系列拆分
- `assets/deskcal-icon.png` / `.ico`：应用窗口、标题栏和 Windows 图标资源
- `scripts/build-icon.py`：从透明源图生成标准 PNG 和多尺寸 ICO
- `src/data-model.js`：schema 版本、数据规范化和旧数据迁移
- `src/main.js`：Electron 生命周期、窗口、托盘、持久化和系统通知
- `src/preload.js`：受限 IPC 桥接
- `src/renderer/`：日历界面和交互
- `tests/`：领域逻辑、迁移、渲染契约和 Electron 冒烟测试

## 节假日数据

2026 年休班数据根据《国务院办公厅关于2026年部分节假日安排的通知》（国办发明电〔2025〕7号）整理，发布日期为 2025 年 11 月 4 日。

农历和节气计算使用 `lunar-javascript`，数据可离线计算。

## 数据位置与兼容

日程默认保存在 Electron 的 `userData` 目录，文件名为 `deskcal-data.json`。写入时采用原子替换，主文件备份（`.bak`）按不少于 10 分钟的时间间隔刷新。若主数据文件损坏，应用启动时会自动从 `.bak` 备份恢复并留存原损坏文件；导入备份前会自动将当前数据留存为 `deskcal-data.json.before-import`。

旧版数据会在启动或导入时自动补充新字段，原有日程不会被修改。旧日程会自动归入默认的“个人”日历。删除操作进入回收站，拖拽和快速调整还可立即撤销。

## 当前边界

- 目前内置 2026 年官方休班安排；其他年份仍可显示农历、传统节日、纪念日和节气
- 年度调休无法通过算法推断，新年份需要根据国务院通知增加数据
- 快速录入采用本地规则解析，不需要联网；少数复杂口语仍可在解析后通过编辑弹窗修正
- 当前为本地单机版本，尚未接入 ICS、Google Calendar、Outlook 或 CalDAV
